# MONO DECK 업무 프리셋

`work-starter.monodeck.json`은 GPT, Claude, Hermes, 웨일, Lightroom 5, OBS의 6개 PC 페이지입니다. 각각 15키와 보조 노브 2개를 포함하며 기기 그룹 1·2·3에 동일하게 배치합니다. 개별 파일도 같은 방식으로 가져올 수 있습니다.

## 가져오기와 내보내기

MONO DECK 왼쪽 메뉴의 **프리셋 라이브러리 → 프리셋 파일 열기**에서 파일을 선택하고, 미리보기에서 추가할 페이지를 고른 뒤 **선택한 페이지 추가**를 누릅니다. 기존 페이지·순서·선택 상태·실행 설정·공통 키는 유지하며, 기기 메모리에는 쓰지 않습니다. 추가 직전에 현재 설정을 데이터 폴더의 `profiles.json.before-presets-시각`에 백업합니다.

같은 추천 프리셋은 다시 추가하지 않으며 기존에 편집한 내용을 유지합니다. 오른쪽 위 노브는 대상 PC의 공통 페이지 전환을 따르고, 나머지 두 노브는 대상 PC의 노브 위치 보정에 맞춰 배치됩니다. 외부 파일의 자동 앱 전환·전역 실행 단축키는 활성화하지 않습니다. 기존 전체 설정 JSON도 새 페이지로 가져올 수 있습니다. 설정의 **전체 설정 백업 복원**은 기존 설정을 교체하는 별도 기능입니다.

**선택 페이지 내보내기** 탭에서 하나 또는 여러 PC 페이지를 프리셋 파일로 저장할 수 있습니다. 서로 페이지 이동으로 연결한 구성은 이동 대상도 함께 선택하세요. 온보드 0, OBS 비밀번호와 오디오 대상 설정은 이 파일에 포함되지 않습니다.

## 노브와 사용 조건

| 페이지 | 왼쪽 작은 노브 회전 / 클릭 | 아래 큰 노브 회전 / 클릭 |
| --- | --- | --- |
| GPT · 앱 기능 | 이전·다음 대화·탭 / 모델·추론 선택 | 포인터 아래 스크롤 / 대화 내 검색 |
| Claude·Hermes | 입력창 단어 단위 커서 이동 / Shift+Enter 줄바꿈 | 포인터 아래 스크롤 / Ctrl+End 끝으로 |
| 웨일 | 이전·다음 탭 / 닫은 탭 복원 | 스크롤 / 페이지 맨 위 |
| Lightroom 5 | 이전·다음 사진 / 확대 전환 | 선택한 슬라이더 증감 / 보정 전 보기 |
| OBS | 이전·다음 장면 후보 / 송출 장면 확정 | 지정 오디오 ±1dB / 음소거 전환 |

오른쪽 위 노브는 모든 페이지에서 이전·다음 페이지 후보, 클릭 확정입니다.

Claude·Hermes 키는 입력창에 요청문만 입력하고 자동 전송하지 않습니다. 먼저 사용할 앱의 입력창을 클릭하세요. GPT는 아래의 실제 앱 단축키 구성입니다. 스크롤은 마우스 포인터 아래에서 작동합니다. 웨일 7번은 선택한 문구를 복사해 검색하므로 클립보드가 바뀝니다. 14번은 네이버 시작 페이지이며 원하는 업무 URL로 편집할 수 있습니다. 15번 메모 양식은 입력란에서 사용합니다.

Lightroom 1·2번은 채택·제외 표시 후 다음 사진으로 넘어갑니다. 텍스트 편집을 끝낸 뒤 사용하세요. 큰 노브는 현상 슬라이더 또는 수치 입력을 먼저 선택해야 합니다. 사용자가 바꾼 앱 단축키와 다른 키보드 배열에서는 조정이 필요할 수 있습니다.

## GPT · 실제 앱 기능 15키 (v2.6.2)

현재 설치된 ChatGPT Windows 앱 26.1111.2228.0의 기본 명령 정의와 [공식 데스크톱 명령 문서](https://learn.chatgpt.com/docs/reference/commands)를 기준으로 구성했습니다. 웹·구형 앱의 단축키와 혼용하지 않습니다. 앱을 앞에 두고 사용하며, 사용자 지정 단축키를 변경했다면 MONO DECK에서도 맞춰주세요.

| 키 | 기능 | Windows 단축키 |
| --- | --- | --- |
| 01 | 새 대화 | Ctrl+Shift+O |
| 02 | 임시 대화 | Ctrl+Shift+N |
| 03 | 명령 메뉴 | Ctrl+Shift+P |
| 04 | 현재 대화 안에서 찾기 | Ctrl+F |
| 05 | 사이드바 접기·펼치기 | Ctrl+Shift+S |
| 06 | 모델·추론 선택 | Ctrl+Shift+M |
| 07 | 최근 모델 선택 | Alt+M |
| 08 | 받아쓰기 켜기·끄기 | Ctrl+Shift+D |
| 09 | 대화 이름 변경 | Ctrl+Alt+R |
| 10 | 대화 고정·해제 | Ctrl+Alt+P |
| 11 | 뒤로 이동 | Ctrl+[ |
| 12 | 앞으로 이동 | Ctrl+] |
| 13 | 대화 링크 복사 | Ctrl+Alt+L |
| 14 | 앱 설정 | Ctrl+, |
| 15 | 단축키 목록 | Ctrl+/ |

임시 대화는 ChatGPT 채팅 모드에서, 받아쓰기는 앱 기능·마이크 권한이 준비된 경우 사용합니다. 모델·추론 선택 화면은 사용 중인 모드에 따라 달라집니다. 전체 대화 검색은 이 버전에서 기본 키가 지정되어 있지 않으며 Ctrl+K는 명령 메뉴입니다. 파일 첨부와 Windows 음성 대화 시작도 확인된 기본 네이티브 단축키가 없어 임의로 넣지 않았습니다. 앱의 단축키 설정에서 원하는 조합을 지정한 뒤 MONO DECK 키에 같은 조합을 저장할 수 있습니다.

## OBS

OBS의 **도구 → WebSocket 서버 설정**에서 서버를 활성화한 다음, MONO DECK **프리셋 라이브러리 → OBS 연결 → 연결 확인·소스 읽기**를 누릅니다. 이 PC의 OBS 설정에서 포트와 인증 정보를 읽어 `127.0.0.1`로 연결합니다. 비밀번호를 별도로 복사하거나 프리셋에 넣지 않습니다.

큰 노브의 캡처 소스와 마이크 대상을 실제 오디오 목록에서 고르고 저장하세요. Windows 전체 볼륨이 아니라 선택한 OBS 소스 볼륨을 조절합니다. 큰 노브는 한 칸당 1dB, 범위 -100~0dB입니다. 음소거는 클릭으로 별도 제어합니다.

작은 노브는 장면 이름을 화면 알림으로 보여주며 클릭할 때만 송출 장면을 전환합니다. 후보는 8초 후 만료됩니다. 키 1~5는 OBS 장면 목록의 순서에 대응하며, 나머지 키는 녹화·마이크·캡처 소스·스튜디오 모드입니다. 리플레이 저장은 OBS 리플레이 버퍼가 실행 중일 때 사용할 수 있습니다. 방송 시작·종료 명령은 이 프리셋에 넣지 않았습니다.

OBS 액션은 PC 전용입니다. 연결이 없으면 오류를 표시하며 자동으로 OBS를 실행하거나 방송·녹화를 시작하지 않습니다. 장면 구성이나 소스 이름을 바꿨다면 연결 화면에서 다시 확인하세요.

## 교회 오디오 믹서 추가 팩 · v2.6.1

`obs-mixer.monodeck.json`은 기존 OBS 장면·녹화 페이지를 그대로 두고 **OBS · 교회 오디오 믹서** PC 페이지를 하나 더 추가합니다. 앱의 **프리셋 라이브러리 → 교회 오디오 믹서** 버튼으로도 열 수 있습니다.

**OBS 연결**에서 `키 01 → HDMI 캡처`, `키 02 → 믹서 USB 오디오`, `키 03 → 송출 PC 데스크톱 오디오`처럼 실제 OBS 소스 이름을 연결하고 **오디오 연결 저장**을 누릅니다. 필요한 키만 사용하며 최대 15개입니다. 이 연결 정보는 해당 PC에만 저장되므로 다른 PC에서는 다시 소스를 연결합니다. 키·노브 프리셋 파일에는 연결 정보나 비밀번호를 포함하지 않습니다.

- 키 1~15: 연결한 오디오를 큰 노브의 조절 대상으로 선택합니다. 선택만으로 볼륨·음소거 상태를 바꾸지 않습니다.
- 큰 노브: 선택 소스의 OBS 볼륨을 한 칸당 0.5dB 올리거나 내립니다. 클릭은 해당 소스 음소거 전환입니다. 액션 편집에서 0.1 / 0.5 / 1 / 2dB 간격을 고를 수 있습니다.
- 왼쪽 작은 노브: 연결된 소스만 순서대로 선택하며, 빈 키는 건너뜁니다. 클릭하면 현재 선택 소스의 볼륨·음소거 상태를 표시합니다.
- 오른쪽 위 노브: 기존 공통 PC 페이지 이동·확정입니다.

선택과 볼륨 조작 시 화면 알림에 실제 소스 이름, dB, 음소거 여부를 표시합니다. 이는 페이더 설정값이며 실시간 신호 레벨 미터는 아닙니다. 앱 재시작 또는 연결 확인 후에는 소스를 다시 선택합니다. 삭제·이름 변경·연결 변경으로 선택 대상이 없어지면 다른 소스를 자동 선택하지 않습니다. 이미 음소거된 소스의 볼륨을 돌려도 음소거가 자동 해제되지 않습니다.

OBS 믹서에 별도 항목으로 나타나는 HDMI 캡처·오디오 인터페이스·데스크톱 오디오는 개별 조절할 수 있습니다. 외부 믹서가 여러 마이크를 합쳐 하나의 스테레오 입력으로 보내면, 그 합쳐진 입력을 조절합니다. 하드웨어 믹서의 개별 채널·프리앰프 게인·현장 PA 출력은 이 기능의 제어 대상이 아닙니다. OBS 화면에서 마우스로 클릭한 채널을 자동 추적하지는 않으며, 위 선택 키 또는 작은 노브로 대상을 정합니다.

## 파일 생성

`node scripts/build-presets.cjs`로 앱 내장 팩과 개별 JSON 파일을 다시 생성합니다. 편집한 개인 프리셋은 앱의 내보내기로 별도 파일에 보관하세요.
